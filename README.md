🧠 Quiz Interativo para Programadores
Este é um projeto prático desenvolvido para consolidar e demonstrar minhas habilidades em HTML5 e CSS3. O objetivo principal foi criar uma interface de formulário interativa, explorando a semântica do HTML e a estilização personalizada.
🎯 Objetivo do Projeto
Desenvolver um site funcional que abra diretamente no navegador, focado em:

    Praticar a estruturação de formulários complexos.
    Manipular diferentes tipos de dados de entrada (input types).
    Explorar recursos avançados de estilização e layout com CSS.

🚀 Tecnologias e Recursos Utilizados
HTML5 (Estrutura)

    Formulários: Uso de radio buttons para múltipla escolha, campos de text e password.
    Tabelas: Organização de dados e informações de forma estruturada (mencionado como diferencial do projeto).
    Semântica: Divisão clara entre cabeçalho, introdução e perguntas para melhor acessibilidade.

CSS3 (Estilização)

    Design Responsivo: Cores de fundo personalizadas e tipografia legível.
    Componentes: Estilização de bordas, arredondamento de campos e realce de links.
    Hierarquia Visual: Diferenciação clara entre títulos, textos explicativos e áreas de interação.

📚 O que este projeto demonstra?

    Domínio de Tags: Uso correto de labels, fieldsets e legendas.
    Lógica de Layout: Como organizar elementos de forma que o usuário entenda o fluxo do quiz.
    Habilidades de Front-end: Capacidade de transformar uma ideia em uma página funcional e visualmente agradável.

💻 Como visualizar

    Baixe os arquivos do repositório.
    Localize o arquivo index.html.
    Clique com o botão direito e selecione "Abrir com o navegador" (Chrome, Edge, Firefox).
